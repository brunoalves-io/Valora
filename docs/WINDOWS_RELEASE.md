# Windows installer

Valora is built on GitHub Actions, so end users do not need Node.js, npm, Rust, or Tauri installed.

## Automatic build

Every push to `main` or a `feat/**` branch runs the Windows build workflow.

The workflow produces an artifact named:

`Valora-Windows-Installer`

It contains the NSIS `.exe` installer generated by Tauri.

## Publishing a release

Once this workflow is present on the default branch:

1. Open **Actions** in GitHub.
2. Select **Valora Windows Build**.
3. Click **Run workflow**.
4. Set **Create a GitHub Release** to true.
5. Enter a tag such as `v0.1.0`.
6. Run the workflow.

When the build succeeds, the installer is attached directly to the GitHub Release.
