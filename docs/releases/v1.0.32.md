# Valora v1.0.32

## Categorização inteligente e regras bancárias

- Sugestões de categoria por regras explícitas.
- Sugestões conservadoras por histórico da própria empresa.
- Regras sempre têm prioridade sobre o histórico.
- Nova coluna Categoria na Conciliação bancária.
- Movimentações já conciliadas também podem receber categoria.
- Criação de regra a partir de uma movimentação.
- Gerenciador de regras com criar, editar, pausar, ativar e excluir.
- Proteção contra regras genéricas como "pagamento".
- Nova RPC de conciliação grava a categoria no mesmo passo da conciliação.

A migration `smart_categorization_rules` já foi aplicada no Supabase.

Build oficial: Windows x64 via Tauri/NSIS.
